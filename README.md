# Вечный секундомер

Простой статический секундомер для GitHub Pages.

- Кнопка запуска только одна.
- После старта остановки и сброса в интерфейсе нет.
- В центре сверху показываются все прошедшие часы, ниже прошедшие дни.
- Общий старт для всех устройств задан в `start.json`: 28.05.2026 14:00.
- Момент старта хранится в браузере через `localStorage`.
- После старта момент также добавляется в URL как `?start=...`, чтобы эту же ссылку можно было открыть с другого устройства.
